# Reglas de codificación para VALHALLA

## Propósito

Estas reglas orientan el desarrollo del proyecto para mantener calidad, consistencia y compatibilidad con los objetivos del producto.

## Reglas generales

- Nunca borrar funcionalidades existentes sin una justificación clara.
- Nunca romper compatibilidad con GitHub Pages.
- Usar JavaScript moderno de forma consistente.
- Separar responsabilidades por módulo y por archivo.
- No duplicar código cuando exista una abstracción clara.
- Documentar funciones importantes, flujos complejos y decisiones de diseño.
- Mantener un diseño responsive y accesible.
- Priorizar claridad antes que complejidad.

## Reglas para GitHub Copilot

- Proponer cambios pequeños y comprensibles.
- Respetar la estructura existente del proyecto.
- Evitar introducir dependencias innecesarias.
- Mantener el código legible y fácil de revisar.
- Preferir mejoras incrementalmente verificables.
- No asumir cambios de comportamiento sin evidencia.

## Reglas de mantenimiento

- Mantener los archivos organizados por propósito.
- Actualizar documentación cuando cambien estructuras o flujos importantes.
- Verificar que los cambios no afecten negativamente la experiencia del usuario.
- Preservar la estabilidad de la aplicación mientras se agregan nuevas capacidades.
