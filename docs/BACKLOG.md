# Backlog de VALHALLA

## Objetivo

Priorizar las tareas necesarias para construir una base sólida, modular y escalable para VALHALLA.

## Prioridades iniciales

### Gestión de finanzas

- Implementar registro de ingresos y gastos.
- Definir categorías personalizadas.
- Crear vistas de resumen y balance.
- Permitir registro de metas financieras.

### Gestión de clientes

- Crear ficha de cliente.
- Registrar pagos y renovaciones.
- Visualizar estado de contratos y vencimientos.

### Gestión de entrenamientos

- Definir ejercicios y rutinas.
- Organizar planes personalizados.
- Registrar progreso por sesión.

### Gestión de nutrición

- Crear planes nutricionales.
- Registrar consumos y hábitos.
- Asociar objetivos con seguimientos periódicos.

### Agenda y organización

- Crear eventos y tareas.
- Vincular agenda con otros módulos.
- Establecer recordatorios básicos.

### IA y asistencias

- Diseñar servicios de análisis de datos.
- Definir flujos de recomendación con aprobación humana.
- Preparar interfaces para mostrar insights de forma clara.

## Criterios de aceptación

- Cada módulo debe ser comprensible y mantenible.
- La experiencia debe mantenerse responsive.
- No se deben introducir cambios que rompan compatibilidad con la plataforma de despliegue.
- La documentación debe actualizarse con cada incremento relevante.

## Versión actual

- Implementación inicial de cuentas operativas y saldo inicial por cuenta.
- Registro rápido con categorías, cuentas, selección de segmento y confirmación clara.
- Dashboard con saldo total, saldo operativo, deuda pendiente y resumen financiero.
- Respaldo mejorado con soporte para cuentas, movimientos, transacciones recurrentes, metas y deudas.
- Preparación inicial de Supabase para autenticación, finanzas y clientes/pagos.
- VALHALLA v0.7 — creación, búsqueda, filtro y listado de clientes con modo local y cloud.
