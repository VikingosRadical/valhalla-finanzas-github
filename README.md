# VALHALLA Finanzas

Aplicación web instalable para controlar ingresos, gastos, clientes, renovaciones y proyección mensual.

## Publicar con GitHub Pages
1. Sube todos los archivos a la raíz del repositorio.
2. Ve a Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: / (root).
6. Guarda.

URL esperada:
https://VikingosRadical.github.io/valhalla-finanzas/

## Datos
Los datos se guardan en el navegador mediante localStorage.
Usa Ajustes > Exportar valhalla.json para respaldarlos.
